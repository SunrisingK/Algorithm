# 数字 2 出现偶数次

## 题目描述

给定两个非负整数 `L` 和 `R`（`0 ≤ L ≤ R ≤ 10^18`），统计区间 `[L, R]` 内，**十进制表示中数字 `2` 出现的次数为偶数**的整数个数。

> 说明：
>
> - “出现 0 次”也算偶数次。例如 `1`、`10`、`345` 都满足条件（不含数字 2）。
> - `22` 中数字 2 出现 2 次，满足；`2`、`12`、`20`、`21` 中数字 2 出现 1 次，不满足。

## 输入格式

一行两个整数 `L R`。

## 输出格式

一个整数，表示区间 `[L, R]` 内满足条件的数字个数。

## 样例 1

输入：

```
1 22
```

输出：

```
18
```

解释：`[1, 22]` 中数字 2 出现奇数次的数为 `2, 12, 20, 21`，共 4 个；区间共 22 个数，故满足偶数次的有 `22 - 4 = 18` 个。

## 样例 2

输入：

```
0 0
```

输出：

```
1
```

解释：数字 `0` 的十进制表示中没有 2，出现 0 次（偶数），满足条件。

## 样例 3

输入：

```
1 100
```

输出：

```
18
```

## 数据范围

- `0 ≤ L ≤ R ≤ 10^18`
- 结果可能很大，需使用 `long long`。
