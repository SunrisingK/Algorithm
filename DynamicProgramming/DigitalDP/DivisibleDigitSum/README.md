# 数位和能被 3 整除

## 题目描述

给定两个非负整数 `L` 和 `R`（`0 ≤ L ≤ R ≤ 10^18`），统计区间 `[L, R]` 内，**十进制表示的各数位之和能被 3 整除**的整数个数。

> 说明：
>
> - 数字 `0` 的数位和为 `0`，`0 % 3 == 0`，满足条件。
> - 例如 `12` 的数位和为 `1 + 2 = 3`，能被 3 整除，满足；`13` 的数位和为 `4`，不满足。

## 输入格式

一行两个整数 `L R`。

## 输出格式

一个整数，表示区间 `[L, R]` 内满足条件的数字个数。

## 样例 1

输入：

```

1 20
```

输出：

```

6
```

解释：`[1, 20]` 中数位和能被 3 整除的数为 `3, 6, 9, 12, 15, 18`，共 6 个。

## 样例 2

输入：

```

0 0
```

输出：

```

1
```

解释：数字 `0` 的数位和为 0，能被 3 整除。

## 样例 3

输入：

```

1 100
```

输出：

```

33
```

## 数据范围

- `0 ≤ L ≤ R ≤ 10^18`
- 结果可能很大，需使用 `long long`。
- 注意，这道题可以直接O(1)时间内算出来，答案 = 区间内3的倍数的个数。
